# 图片审查环节（Figure Review）

> 用途：图片是论文的"门面"，编号错位、标题重复、标注裁切、箭头杂乱是评审一眼可见的硬伤。
> 本环节在阶段2（生成后）、阶段3（插图后）、阶段4（终审前）各执行一次。**每次生成/重绘图片后必须过一遍本清单。**

---

## 一、铁律：每个图只保留一个"图片上方"的编号+标题

- ✅ 论文中的图题由 **LaTeX 图注统一给出**，`\caption` 必须写在 `\includegraphics` **之前**（图题在上）；
- ✅ **图内不再设置任何标题**：`ax.set_title(...)` 一律删除——图内标题会与图注重复、且硬编码编号极易与文档图序错位（典型事故：文档图序 图3 下方图片内却写着"图2"）；
- ✅ 图表编号由 LaTeX `\label`/`\ref` 自动生成，新增/删除图表后无需手改编号。

## 二、编号一致性核对（最易错）

1. **确定文档图序**：按 `\includegraphics`/`\caption` 在正文中的出现顺序排 图1、图2、…、图N；
2. **图内不得出现任何"图X"字样**（已由铁律一禁止）；
3. **正文引用**（"如图X所示""图X展示"）用 `\ref{fig:...}` 或与 LaTeX 编号核对一致；
4. **markdown 预览**（如 final_paper.md）中的图序同样要与文档图序一致，且图题写在图片行**上方**（`**图N 标题**` 空行后接 `![图N](路径)`）；
5. 新增/删除任何图后，重新核对整张图序表，禁止"图8 放在 图2 的位置"式错位。

## 三、单图质量检查项

| 检查项 | 标准 | 自检 |
|--------|------|------|
| 图题位置 | 图题在图片上方（`\caption` 先于 `\includegraphics`），全文唯一 | □ |
| 图内标题 | 图内无 `set_title`，无重复"图X"字样 | □ |
| 3D 图坐标轴 | x/y/z 轴标签完整、无裁切（`labelpad` + `fig.tight_layout(pad>=1)` + 画布留足高度） | □ |
| 流程图箭头 | 箭头贴边、无交叉缠绕、方向单一（尽量只做垂直流向） | □ |
| 文本框文字 | 文字完整落在框内、不超边界（`ax.text` 不自动换行，长文本必须手动 `\n` 拆行） | □ |
| 无冗余标注 | 无"箭头旁注/说明性散字/无关装饰"等多余文字 | □ |
| 中文标注 | 图内中文 SimHei 无乱码、无豆腐块 | □ |
| 分辨率 | ≥300 DPI；放大 200% 无马赛克 | □ |
| 尺寸 | 宽度 8-16cm（打印尺寸），无水印、无模糊拉伸 | □ |
| 配色 | 学术配色，灰度下仍可辨识 | □ |
| 图注 | 每图配 50 字内专业图注（LaTeX 图注中给出） | □ |
| 嵌入质量 | PDF 中图片清晰嵌入、不跨页割裂、不压版心 | □ |

## 四、执行时机

- **阶段2 编程手**：每生成/重绘一张图即自查 1-3 条铁律（无内嵌标题、图序表记录）；
- **阶段3 论文手**：插图后核对"LaTeX 图注编号 == 正文引用编号"，跑一遍 表三 单图质量项；
- **阶段4 终审**：五步终审中的"导出预览校验"前，对全部图逐张过 表三；任何图重绘后必须重新编译 PDF 并复跑 `format_check.py`（图序/引用审计）与 `depth_check.py`（图数量 ≥8）。

## 五、流程图专项（技术路线/流程示意图）检查

> matplotlib 画流程图的三大高频事故：箭头插进文本框、文字超出框边界、无关旁注残留。逐条按下列实现约定规避。
> **2026-08 增强**：融合 `diagram-design`（形状承载类型/焦点规则/连接线卫生/复杂度预算）、`multi-chart-draw`（Mermaid 草稿先快后精/决策分支带标签）、`scientific-toolkit-skill`（矢量输出/色盲安全/灰度检验）的画图规范；完整模板见 `workflow_figure.md`。

| 检查项 | 标准 | 实现约定 |
|--------|------|---------|
| 箭头贴边不插盒 | 箭头只出现在行间空隙，箭头尖精确落在下一行盒子视觉上边，绝不进入盒内 | ① `FancyBboxPatch` 的 `boxstyle='round,pad=PAD'` 会把盒子向外扩 `PAD`；箭头终点必须取**视觉上边 = 标称 y+h+PAD**、起点取**视觉下边 = 标称 y−PAD**；② **先画全部箭头、后画盒子**，即使残余穿入也被盒子盖住 |
| 全垂直单向流 | 箭头尽量只做上→下垂直流向，杜绝交叉 | 各层盒子等距排布，箭头共用同列 x 坐标；合并/汇总层用全宽单盒而非多盒，避免扇出交叉 |
| 文字不溢出 | 每格文本完整落在框内，最长行宽度 < 框宽 | `ax.text` **不自动换行**，长文本必须手动用 `\n` 拆 2 行；行内字符数与框宽换算（中文≈字号×0.5×字数），超宽即缩短文字或降字号 |
| 无无关旁注 | 图中除必要标注外无多余说明性文字 | 删除 `ax.annotate`/散置文本，图题与必要图注统一交给 LaTeX 图注 |
| 行高留白 | 多行文本纵向不顶天立地 | `ax.text(linespacing=1.5)` + 盒高至少容纳 `行数×字号×1.5` |
| 箭头方向正确 | `annotate` 的 xy=箭头终点(尖)、xytext=起点；方向向下时尖朝下 | 方向向下：`xy=(cx, 下盒顶+0.03)`、`xytext=(cx, 当前盒底-0.05)`，`arrowstyle='-|>'`；画完箭头后用 `Get-FileHash` 核对 PDF 是否真正更新（改图后删 `main.aux` 重编译） |
| 分层次设计 | 单色等大直排盒无"思考度/对比/重点"；左/右侧冗余标注反而干扰 | **三色原则**（≤3 色系：主流程蓝 + 核心决策橙高亮 + 目标/结论深蓝）+ 顶部目标盒/底部结论盒 + 核心阶段加粗边框 + 左侧层次标注**直接平放**（不旋转、不嵌文本框，竖虚线归纳"数据/建模/决策/判定/检验/交付"层）+ **去掉"产出"等冗余标签** + 粗实线单向向下箭头 |
| 特殊字符不依赖中文字体 | `²³⁴` 等 Unicode 上标在 SimHei 下变方块 | 物理单位用 mathtext `'kg/m$^2$'`（stix 渲染）；图内检索替换 `²` 等特殊字形 |
| **形状承载类型**（diagram-design） | 节点类型由**形状**表达，不由颜色表达 | 起止=椭圆、步骤=圆角矩形、决策=菱形（`Polygon`）、汇合=实心圆点；同类节点形状必须一致 |
| **焦点规则**（diagram-design） | 强调色只给 1–2 个最关键元素，全图不超 2 个 | `focal_i` 至多高亮 1 个核心问题框；决策菱形用强调橙；其余统一克制配色 |
| **标签留空**（diagram-design） | 箭头标签与连接线之间留 6–10px 视觉空隙，不压线 | 白底 `bbox` 底边与线条之间留 ≥6px；垂直箭头的标签放线侧，不放线上 |
| **分锚点**（diagram-design） | 同一盒子边缘多箭头时各自独立锚点，不共享、不粘连 | 同边 N 根箭头的锚点间距 ≥12px；两箭头并排同行时全程间距 ≥12px |
| **复杂度预算**（diagram-design） | 单图盒子 ≤9、箭头 ≤12；超了拆"总览 + 详图" | 子问题 >5 时先拆；两盒总一起出现就合并成一盒（删除测试） |
| **决策分支带标签**（multi-chart-draw） | 决策菱形每个出口都有文字标签，无裸出口 | `|是|`/`|否|` 逐条标注；出口 >3 拆嵌套菱形 |
| **矢量双写**（scientific-toolkit） | 线稿存 PDF/SVG + 300DPI PNG，不提交 JPEG | `savefig('.pdf')` 与 `('.png', dpi=300)` 双写；LaTeX 直插 PDF 保证矢量 |
| **灰度可辨**（scientific-toolkit） | 去色/色盲后各层仍可区分 | 配色用 Okabe-Ito 兼容色（蓝 #2166AC 橙 #D55E00 绿 #2E8B57…），保存后转灰度目检 |

## 六、常见事故与修复

| 事故 | 根因 | 修复 |
|------|------|------|
| 图X标题下方出现"图Y" | 图内 `set_title` 硬编码编号与文档图序错位 | 删除图内标题，图题统一交给 LaTeX 图注 |
| 3D 图 z 轴标签被裁 | 画布高度不足 / tight_layout pad 太小 | 增大 figsize 高度 + `zlabel(labelpad=16)` + `tight_layout(pad=1.2)` |
| 流程图箭头杂乱 | 箭头交叉、多向流 | 重排为垂直单向流，去掉交叉水平箭头 |
| 箭头插进文本框 | `boxstyle` pad 外扩盒子而箭头终点按标称边界算 | 箭头终点取视觉上边（y+h+pad），且先画箭头后画盒子 |
| 文本超出框边界 | `ax.text` 不换行、单行过长 | 手动 `\n` 拆行 + 精简文字/降字号 |
| 图注与正文引用编号不符 | 增删图后手改编号漏改 | 全用 `\ref`；或改动后逐条核对图序表 |
| 箱线图离群点圆圈重叠 | `boxplot` 默认 `showfliers=True`，多离群值时圆圈互相遮挡 | `showfliers=False` 隐藏，另加红色均值点展示组间差异 |
| 流程图表意不清/结构僵硬 | 标题与内容挤在一格、字号过大 | 标题区与内容区分栏排版（左标题右内容），统一盒宽盒高，文字手动 `\n` 换行 |

## 七、箱线图专项（数据分布类图）

| 检查项 | 标准 | 实现约定 |
|--------|------|---------|
| 离群点不重叠 | 多离群样本时圆圈互相遮挡，无法读数 | `boxplot(..., showfliers=False)` 隐藏 flier 圆圈；或用 `sym='k.'` 缩小为点 |
| 组间差异可视化 | 仅箱体难直观比较组均值 | 叠加红色均值点 `ax.plot(k+1, np.nanmean(arr), 'o', mfc='#D6604D')` |
| 图序核对 | 用户所指"图X"按 PDF `\includegraphics` 顺序而非文件名序 | 核对文档图序表后再定位（实战：论文"图10"是 fig12_z_box.png） |
