# 国赛高频模型与算法全库

## 一、按题型分类的首选模型速查

| 题型分类 | 题目特征 | 首选模型 | 备选模型 | 必备检验 |
|---------|---------|---------|---------|---------|
| 优化类-线性 | 线性约束、简单规划 | 线性规划 | 整数规划 | 可行解检验、最优性检验 |
| 优化类-非线性 | 非线性/复杂约束 | 非线性规划 | GA/PSO | 收敛性、全局最优 |
| 优化类-多目标 | 多目标冲突 | 组合赋权+多目标规划 | NSGA-II/理想点法 | 帕累托前沿、敏感性 |
| 优化类-组合 | 离散组合/路径 | Dijkstra/GA | ACO/SA | 多次运行稳定性 |
| 优化类-多阶段/多级 | 工序/装配网络/多阶段决策 | 状态-决策模型+动态规划 | 多级期望递推 | 最优子结构、记忆化、无后效性 |
| 统计抽样-假设检验 | 抽检/接收判定/样本量设计 | 假设检验+决策函数权衡 | 序贯概率比检验(SPRT) | 功效函数、两类错误率 |
| 不确定优化-参数扰动 | 参数带误差/服从分布 | 贝叶斯共轭先验(后验解析积分) | 蒙特卡洛/区间鲁棒 | 后验推导、超参数灵敏度 |
| 评价类-主观 | 无大量客观数据 | AHP层次分析 | - | CR<0.1一致性检验 |
| 评价类-客观 | 有完整量化数据 | 熵权-TOPSIS | CRITIC/变异系数 | 指标正负向标准化 |
| 评价类-模糊 | 模糊定性指标 | 模糊综合评价FCE | 灰色关联GRA | 隶属度矩阵检验 |
| 预测类-小样本 | 小样本/贫信息 | GM(1,1)灰色预测 | 指数平滑 | 级比检验/后验差检验 |
| 预测类-时序 | 连续时序数据 | ARIMA/SARIMA | Prophet | ADF平稳性/残差正态 |
| 预测类-大数据 | 大数据量/高维 | XGBoost/RandomForest | LSTM/BP | K折交叉验证 |
| 机理类-物理 | 力学/运动/传热 | 常/偏微分方程 | 动力学方程组 | 初值边值合理性 |
| 机理类-因果 | 时序因果溯源 | 格兰杰因果检验 | 中介效应/调节效应 | 平稳性预处理 |

## 二、优化类模型详解

| 模型类型 | 适用场景 | 推荐求解算法 | 必备检验 |
|---------|---------|------------|---------|
| 线性规划 | 目标函数和约束均为线性 | 单纯形法、Lingo | 可行解、最优解、退化解判定 |
| 整数/0-1规划 | 决策变量为整数或二元 | 分支定界法、割平面法 | 松弛解与整数解间隙、可行解校验 |
| 非线性规划 | 含平方/指数/乘积等非线性项 | 拟牛顿法、GA、PSO | 迭代收敛性、局部vs全局最优 |
| 多目标规划 | 多目标冲突需权衡 | 权重法、NSGA-II | 帕累托前沿有效性、权重敏感性 |
| 动态规划 | 以时间划分阶段的优化 | 逆序递推/顺序递推 | 最优子结构、无后效性 |
| 状态-决策模型+DP | 多工序/多级装配网络决策（含检测/拆解状态(d,q,r)） | 记忆化递归/逆序递推 | 最优子结构、记忆化存储、状态转移完整性 |
| 决策函数权衡法 | 抽样样本量/检测次数最小化（成本×功效权衡） | 遍历+积分寻优 | 功效函数、成本权重 w₁/w₂、先验积分收敛 |
| 组合优化 | TSP/调度/路径规划 | ACO、SA、GA | 迭代收敛曲线、多次运行稳定性 |

## 三、评价类模型详解

| 模型类型 | 适用场景 | 必备检验 | 核心校验要点 |
|---------|---------|---------|------------|
| AHP层次分析 | 有专家经验、指标分层清晰 | 一致性检验CR<0.1 | 判断矩阵归一化、层次权重合理性 |
| 熵权法 | 有完整数据、无专家主观打分 | 信息熵指标离散度 | 剔除低区分度无效指标 |
| CRITIC法 | 多指标综合评价 | 指标标准差+相关系数 | 对比强度与冲突性计算 |
| TOPSIS | 多对象优劣排序 | 正负理想解计算 | 同向化、无量纲化、贴近度 |
| 灰色关联分析 | 分析各因素对结果的影响程度 | 关联度排序检验 | 分辨系数选取 |
| 模糊综合评价 | 模糊定性指标/等级判断 | 隶属度矩阵检验 | 评语集/权重集构建、去模糊化 |
| DEA | 效率/投入产出评价 | 效率值分布检验 | 投入产出指标正向性 |
| 秩和比法 | 多指标综合水平评价 | 秩次分配检验 | 常用于医学研究领域 |

## 四、预测类模型详解

| 模型类型 | 适用场景 | 必备检验 | 核心校验要点 |
|---------|---------|---------|------------|
| GM(1,1)灰色预测 | 小样本、贫信息、短中期 | 级比检验、后验差检验 | 模型精度评级(P>0.95, C<0.35优) |
| ARIMA时序 | 平稳时序/有周期性 | ADF检验、白噪声检验、残差正态性 | AIC/BIC准则择优 |
| SARIMA | 有季节性的时序 | 季节分解检验 | 季节性阶数确定 |
| Prophet | 强季节性+节假日效应 | 趋势+季节性分解 | 变点检测 |
| 多元回归 | 受多个明确因素线性影响 | VIF共线性、异方差、DW检验 | 拟合优度R²、系数显著性 |
| 岭回归/Lasso | 高维共线性数据 | 正则化参数调优 | 交叉验证选λ |
| RandomForest | 大数据量/非线性 | OOB误差、特征重要性 | 过拟合检验 |
| XGBoost/LightGBM | 竞赛级高精度预测 | K折交叉验证、MSE/MAE | 过/欠拟合校验 |
| BP神经网络 | 非线性映射关系 | 训练/测试集划分、MSE | 过拟合、收敛速度 |
| LSTM | 长序列时序预测 | 同机器学习模型 | MSE/MAE误差检验 |
| 马尔可夫预测 | 状态转移/当前仅与前一状态相关 | 状态区间划分 | 转移概率矩阵归一化 |

## 五、数据处理方法速查

| 场景 | 推荐方法 | 说明 |
|------|---------|------|
| 缺失值<5% | 均值/中位数填充 | 简单快速 |
| 缺失值5%-30% | 拉格朗日/牛顿插值 | 保持数据趋势 |
| 缺失值>30% | 预测模型填充 | 回归/KNN预测 |
| 异常值检测 | 3σ准则+箱线图+LOF | 多方法联用校验 |
| 标准化 | Z-score（标准差法） | 适合正态分布数据 |
| 归一化 | Min-Max（极值差法） | 适合有界数据 |
| 分类变量编码 | 独热编码/标签编码 | 视模型需求选择 |
| 降维 | PCA主成分/T-SNE/UMAP | 高维数据预处理 |
| 平滑去噪 | Savitzky-Golay/滑动平均 | 曲线平滑 |

## 八、聚类/分类/统计/图论速查（书 §3）

| 题型 | 题目特点 | 推荐模型 | 必备检验 |
|------|---------|---------|---------|
| 聚类-无监督 | 无训练数据、自主划分样本 | K-Means、层次聚类、高斯混合、SOM | 肘部法则定 K、轮廓系数、组内相似/组间差异、结果稳定性 |
| 聚类-密度 | 高维/不规则/含噪声 | DBSCAN | eps 与 min_samples 调参、噪声识别剔除、密度一致性 |
| 分类-有监督 | 有标签样本、判别未知样本 | 逻辑回归、SVM、随机森林、KNN | 混淆矩阵、准确率/召回率/F1、ROC-AUC、过拟合校验 |
| 相关性分析 | 变量间关联程度与方向 | Pearson/Spearman/Kendall、卡方检验 | 正态性检验(Pearson)、显著性 p 值、系数大小合理解读 |
| 拟合分析 | 挖掘变量间函数关系 | 多项式/非线性曲线拟合 | 拟合优度 R²、残差随机性、避免高阶过拟合 |
| 图论-最短路径 | 两个/每对顶点最短路径 | Dijkstra、Floyd | 边权合理性、路径最优性验证 |
| 图论-组合优化 | TSP 旅行商等离散组合 | 图+规划模型、GA/ACO | 多次运行稳定性、最优解偏差 |

## 九、模型选择决策链（书 §2 核心速记）

```
优化题：线性→LP；整数→IP/0-1；非线性→NLP+GA/PSO；多目标→NSGA-II/理想点法；分阶段→动态规划；多级/网络→状态-决策模型+DP（或多级期望递推）
抽样/决策题：抽检→假设检验+决策函数权衡(成本×功效)；多环节决策→决策树/0-1枚举+显式期望推导(二项/几何分布)
评价题：无数据→AHP(CR<0.1)；有数据→熵权-TOPSIS；模糊→FCE/灰色关联；效率→DEA
预测题：小样本→GM(1,1)；时序→ARIMA/SARIMA；大数据非线性→RF/XGBoost/LSTM
机理题：动力学→ODE/方程组；演化→SIR/Logistic/SD；隐性关联→SEM
数据题：清洗(分级填充+3σ/箱线/LOF)→变换(Z-score/Min-Max/编码)→特征工程(PCA)→聚类/分类/关联
```

## 十、贝叶斯统计与不确定优化方法（2024B 优秀论文口径）

| 方法 | 适用场景 | 关键步骤 | 必备检验 |
|------|---------|---------|---------|
| 贝叶斯共轭先验 | 参数带不确定性、需解析后验 | 选共轭先验（二项↔Beta、泊松↔Gamma）→ 后验更新 → 目标对后验解析积分 | 先验超参数灵敏度（如 α,β∈{1..10} 结果稳定） |
| 贝叶斯点估计 | 由样本估计参数再决策 | 最大后验估计 / 后验均值 | 与点估计结果对比、区间宽度 |
| 蒙特卡洛参数抽样 | 复杂模型无法解析积分 | 参数按分布/置信区间抽样 → 重解 → 统计决策频率/绩效 | 决策频率、失效概率、期望损失、样本量收敛 |

**要点**：目标函数含参数 $p$ 时，把"点估计代入"升级为"对 $p$ 的后验/抽样分布求期望"是拉分关键；未检件"是否次品"的分布可对参数分布积分得到边际概率（如 $P(X=1)=p_0$）。
