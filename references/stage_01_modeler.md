# 阶段1：建模手 → modeling_thought.md

> 目标：产出全链路建模思路文档，让编程手可直接写代码、论文手可直接写作。建议耗时 6-12h。

## 入口条件

- 阶段0 完成：题号/题型/问题数已在 state；
- 题面与数据已读完。

## 加载

- `references/seven_steps.md`（七步解题法 + 各题型全流程）
- `references/score_modules.md`（四大得分模块 + 三大检验）
- `references/innovation_paths.md`（五大创新路径）
- `references/model_catalog.md`（模型选型）
- `templates/modeler_output.md`（输出结构）
- 光谱/周期信号类题目（薄膜干涉、频谱分析、波形反演等）另加 `references/spectral_processing_notes.md`（闭式反演式含群速度/群折射率色散修正、三方法周期估计设计、高阶效应判据）

## 任务

按 `templates/modeler_output.md` 结构产出 `<PROJECT_ROOT>/modeling_thought.md`：

1. **赛题深度解析**：背景痛点、已知条件约束、子问题拆解表、递进逻辑、思维导图；
2. **题型判定**：每问归类 + 判定依据；
3. **数据需求分析**：自带数据梳理、需检索数据、缺失参数假设；
4. **模型假设**（3-5 条，分类 + 依据 + 影响）；
5. **符号说明**（三线表，区分变量类型）；
6. **每个子问题的模型构建**：选型对比（≥2-3 候选 + 理由）→ 原理 → **创新点设计（标注五大路径之一）** → 公式推导（≥10 公式/问，分步+编号）→ 建模流程图（中文标注）；
7. **模型检验方案设计**：误差/灵敏度/稳健性/对比，逐问列出指标与合格阈值；
8. **模型改进与推广**；
9. **全链路思路总结**（给论文手直接参考）。

**质量红线**：
- 禁止黑箱：每个选型写清"为什么选它不选其他"；
- 创新点显性化：明确标注属于五大创新路径哪一类（`references/innovation_paths.md`）；
- 符号全文统一，公式分步推导、编号规范；
- 流程图/思维导图原创生成、配色美观、中文标注（SimHei 无乱码）。

## 出口门禁（L1 评分，1-10 分）

| 维度 | 检查点 |
|------|--------|
| 问题理解 | 每问目标/约束/递进逻辑清晰 |
| 模型选型 | 有 ≥2-3 候选对比 + 选型理由 |
| 创新设计 | 每问有明确创新点并标注路径 |
| 公式推导 | ≥10 公式/问，分步、编号、符号统一 |
| 检验方案 | 误差/灵敏度/稳健性逐问有指标与阈值 |
| 落地可执行 | 编程手能直接据此写代码 |

- 任一维度 <7 → `refine`（定向补该维度，iter≤2）；
- 存在 high 级问题（如公式推导错误、选型无理由）→ `block`。

**L2 备注**：本阶段记录到 state 的模型名称、创新点、关键数值，后续阶段必须与其一致。
