# 国赛附录写作指南（附录四件套，对齐 2024B 官方优秀论文）

> 依据：2024 国赛 B 题官方优秀论文附录逐页精读（P24-37 共 14 页）。该论文把**全部求解代码完整贴入附录**，并在附录开头放两张目录表，评审 10 秒即可定位任意代码。2026 起正文（题目→摘要→…→参考文献）限 **30 页**，附录不计页数——**附录是唯一不限篇幅的得分区，代码放得越完整、复现性越强，加分越多**。

---

## 一、优秀论文附录长什么样（逐页拆解）

```
附录（起始页：先有「附录」大标题，如 \section*{附录：代码与数据说明}，不得跳过直接进入运行环境说明）
  表1 支撑文件目录        ← 支撑文件名称 → 文件内容 对照表（如：问题一代码.R → 问题一求解代码）
  表2 附录目录            ← 附录1-6 → 名称 对照表
  附录1 问题一求解代码     ← R 完整代码（含函数、遍历、积分）
  附录2 问题二求解代码     ← R 完整代码（含 16 方案期望表达式实现）
  附录3 问题三求解代码     ← Python 完整代码（状态-决策 DP + 记忆化）
  附录4 问题四求解问题二代码 ← R 完整代码（cubature 三重积分）
  附录5 问题四求解问题三代码 ← Python 完整代码（Beta 分布积分）
  附录6 灵敏度检验代码     ← R 完整代码（α/β 超参数变动）
```

**三个关键特征**：
1. **先目录后代码**：表1 支撑文件目录 + 表2 附录目录，让评审 10 秒定位。
2. **代码按"问题×求解"拆分**：一个求解环节一个附录，不是把全部代码揉成一坨。
3. **代码完整粘贴**：每段是**整个脚本**（函数定义+参数+主流程+输出），**不是关键片段**；R/Python 按各问最适合的语言混用。

## 二、附录四件套（本 skill 的强制结构）

> **编号口径（强制）**：附录一律用**阿拉伯数字**（附录1、附录2、…），**禁止用字母**（附录A/B/C）；表1「支撑文件目录」的"对应附录"列、表2「附录目录」、各附录章节标题、正文"见附录 X"引用必须互相一致。

### 第 3 件：分问全量代码（核心）
- **按问拆分**：每问一个（或一个求解环节一个）附录章节，章节内用 `lstlisting` 完整粘贴对应 `code/*.py` 的**全文**。
- **代码质量要求**（编程手就应保证）：
  - 每个文件头部有模块注释：文件名、功能、对应正文节号/表号、运行环境；
  - 逐行/逐块中文注释，无黑箱；
  - `if __name__ == '__main__':` 可独立运行；
  - 随机种子固定、无硬编码路径、结果可复现。
- **正文↔附录对照**：每个代码附录开头一句话说明"本代码对应正文第 X 节 / 表 X 的结果"，让评审能按图索骥。
- **禁止**：只贴关键片段、删掉函数体留占位、把全部代码塞进一个附录。

### 第 4 件：运行环境说明
附录开头（表1 之前）给出一段运行环境：
```
运行环境：Python 3.12，numpy / scipy / pandas / matplotlib / sklearn
依赖清单：见 code/requirements.txt
一键复现：python main_solver.py
```

### 附加：数据 / 推导 / AI 说明（按需）
- 原始与处理后数据（关键表）、复杂推导补充、额外仿真；
- **附录 AI 使用说明**（2026 强制）：工具名称、版本、开发方、使用日期、使用环节与用途，声明核心建模与推导由队伍完成、AI 生成内容经人工审核。

## 三、正文页数与附录的关系（2026 新口径）

| 项目 | 口径 |
|------|------|
| 正文 | 题目 → 摘要 → … → 参考文献，**≤30 页**，无目录 |
| 附录 | **不计页数**，从参考文献后另起，可到几十页 |
| 参考模板 | 优秀论文 = 23 页正文（题目→参考文献）+ 14 页附录 = 37 页 |
| 对策 | 正文只放"建模+推导+结果表"（做足 23-30 页），**把所有代码细节全部下沉附录**，正文不粘贴长代码 |

**写作原则**：正文里出现"结果见附录 X / 代码见附录 X"即可，代码本体全放附录；正文篇幅全部让给推导过程与全量结果表。

## 四、附录落地检查清单（阶段3 出口自检）

- [ ] **附录用数字编号（附录1、附录2…），无字母（附录A/B/C）；表1"对应附录"列与附录实际编号一致**
- [ ] 附录有表1「支撑文件目录」（code/ 每个文件一行）
- [ ] 附录有表2「附录目录」（附录编号→名称）
- [ ] 代码按问拆分，**每个附录对应一个 code/*.py 的完整全文**（lstlisting），非关键片段
- [ ] 每个代码附录开头有一句话"对应正文第 X 节/表 X"
- [ ] 附录开头有运行环境 + 一键复现说明
- [ ] 附录含 AI 使用说明（2026 强制）与数据说明（按需）
- [ ] 附录代码与 `code/` 实际文件一致（防止"附录代码跑不出正文结果"）
