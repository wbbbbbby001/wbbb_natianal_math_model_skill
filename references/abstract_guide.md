# 国赛摘要写作指南

> 权威口径：《2026 国赛三天速成国奖》宝书 §7.3.3 / §7.3.5 / §8.1。
> 摘要是国赛评审**第一眼、第一关、第一权重**内容，初审评委仅用 5-10 分钟看摘要决定是否进终审。**摘要占总成绩约 40%**。

## 一、基础硬性标准

- **字数：800-1000 字**，PDF 版面控制**单页内**（占页面 3/4 或 4/5 最佳）；
- 格式：纯文字，无口语、无问句、无感叹句、无公式、无图表、无引用标注；
- 写作顺序：**摘要最后写**！正文（建模+求解+图表+检验）完成后再提炼，修改次数 **≥5 遍**。

## 二、黄金三段式结构（字数严格卡死）

| 段落 | 内容 | 建议字数 |
|------|------|---------|
| 第一段（虎头） | 行业背景价值 → 技术现实痛点 → 本文建模解决方案（整体框架） | 150-200 字 |
| 第二段（猪肚） | 数据预处理 + **逐个子问题**（模型+算法+创新+量化结果） | 450-550 字 |
| 第三段（豹尾） | 创新点总结 + 各类检验（灵敏度/稳健性）+ 模型优势 + 推广价值 | 200-250 字 |

**第二段内部**：每个子问题都必须有 模型名称 + 求解算法 + 量化结果，以「针对问题 X」开头分段。

## 三、高分要素与扣分雷区（书 §7.3.3）

| 核心要素 | 高分标准 | 扣分雷区 |
|---------|---------|---------|
| 字数篇幅 | 800-1000 字，版面饱满紧凑 | 超一页、不足 600 字、段落零散 |
| 结果呈现 | 全量化数据、精度、优化比例、误差指标 | 模糊描述（效果显著、有所提升）、无具体数值 |
| 模型表述 | 写明基础模型、改进点、求解算法 | 仅写"建立模型"，不标注方法与创新 |
| 逻辑结构 | 问题→数据处理→模型→结果→检验闭环 | 逻辑跳跃、分问题顺序混乱、前后矛盾 |
| 内容规范 | 纯文字，无公式、图片、脚注、引用 | 夹带公式编号、图表符号、参考文献标注 |
| 语言风格 | 学术书面语、句式严谨、术语准确 | 大白话、网络用语、主观臆断（我认为、显然） |
| 创新表述 | 明确写出模型改进、算法优化、思路创新 | 通篇无创新描述 |
| 模型检验 | 包含灵敏度分析、稳健性检验、对比验证 | 只有结果，无任何可靠性验证 |

## 四、8 条写作策略（书 §7.3.5）

1. **时间规划**：摘要最后写，正文→提炼核心数据与创新点→初稿→精简→5 轮修改定稿；
2. **结构执行**：三段式字数卡死（150-200 / 450-550 / 200-250）；
3. **内容填充**：四大必备要素缺一不可——数据处理方法、模型与创新点、量化结果、模型检验（≥2 种）；
4. **分题型适配**：A 题侧重物理机理/参数优化；B 题侧重规划模型/约束条件；C 题侧重数据清洗/机器学习；
5. **语言精简**：禁止"随着社会快速发展"等万能套话；合并短句提升信息密度；术语统一；
6. **数据规范**：摘要数据必须与正文图表完全一致，禁止估算编造；误差/提升率保留 1-2 位小数（7.9%、4.12%）；专业指标用 RMSE/MAPE/R²；
7. **创新凸显**：改进点放在每个子问题句中核心位置；写法"针对传统 XX 模型存在 XX 缺陷，本文引入 XX 构建改进 XX 模型"；搭配"相较传统模型，XX 指标降低/提升 XX%"；
8. **自查验收**：定稿前逐行过 5 审清单（见 `templates/abstract_checklist.md`）。

## 五、摘要终极避坑 5 条铁律

- 禁止背景铺垫过长（占比不超全文 1/4），头重脚轻；
- 禁止无量化结果、无创新点、无模型检验三大核心内容；
- 禁止出现疑问句、感叹句、主观评价类情绪化语句；
- 禁止语句冗余、重复表述，一字不多、一字不少；
- 禁止夸大，数据与正文完全一致（严禁数据造假/前后不符）。

## 六、万能写作模板（书 §7.3.6）

**第一部分（单句连贯总起，3-5 行，一句话写完）**：
当前【行业/物理工程/数据业务场景】普遍存在【成本高/预测偏差大/参数匹配失衡/决策主观性强】等现实痛点，传统人工经验与单一数学方法难以实现全局最优量化方案，本文围绕赛题给出的【实测数据集/物理机理约束/工程运行规则】，依次针对问题一、问题二、问题三开展完整建模分析，综合搭建集数据清洗、机理/统计建模、智能算法寻优、可靠性验证于一体的组合模型体系，并依托【遗传算法/蒙特卡洛模拟/整数规划/时序分析算法】完成全部子问题迭代求解与定量计算。

**第二部分（每个子问题一个独立段，以「针对问题 X」开头）**：
针对问题 X，该子问题核心解决【参数求解/销量预测/方案筛选】问题，本文首先利用【3σ准则+IQR/滤波降噪】方法对全量原始数据进行标准化预处理，然后开展【相关性分析/机理推导/分布拟合】深度分析，构建【改进时序预测模型/微分动力学模型/整数规划模型】，并利用【变步长搜索/网格遍历/最小二乘法】数值方法进行求解，得出【误差降低 XX%/最优参数集/初步可行方案】的定量结果。

**第三部分（检验+评价+应用价值）**：
最后对模型的鲁棒性和灵敏度进行检验，结果显示【参数扰动 ±10% 时结果偏差 ≤5%，模型稳健；替换算法后结论一致】，证明模型可靠性。本文模型还可推广至【同类场景】，具备较高工程应用价值。
