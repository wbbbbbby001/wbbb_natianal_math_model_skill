# 格式硬检测规则（论文输出前强制执行）

> 权威口径：《2026 国赛三天速成国奖》宝书 §7.2 / §7.6 / §8.6。论文全部完成后按顺序逐项检查，全部通过才允许输出最终版本。

## 检测项总览（优先级从高到低）

### 第一检：合规红线（书 §8.6）——任一不通过即 block
```
□ 匿名：全文（含标题、页眉页脚、图表、附录、代码注释、文件名、文档属性）无姓名/学校/学号/战队名/校徽Logo/参赛编号
□ 查重意识：问题重述自主改写（不抄原题）；模型原理用自己的语言；图表代码原创；全文重复率目标 ≤20%
□ AI 披露：附录4「AI使用说明」存在且按 2026 国赛要求填写
□ 提交时间：预留 ≥1 小时做 MD5 上传 + PDF+支撑材料提交
```

### 第二检：摘要专项（书 §7.3.3）
```
□ 字数 800-1000 字
□ 篇幅单页内，占 3/4-4/5 最佳，不溢出
□ 严格三段式（虎头 150-200 / 猪肚 450-550 / 豹尾 200-250）
□ 纯文字：无公式、无图表、无引用标号、无问句、无感叹句、无口语
□ 每个子问题都有：模型名称 + 求解算法 + 量化结果
□ 写明创新点 + 至少两种模型检验方式
□ 所有数值与正文图表完全一致（误差/提升率保留 1-2 位小数）
```

### 第三检：结构完整性（书 §7.1）
```
□ 12 模块齐全且顺序正确：题目→摘要→关键词→问题重述→问题分析→模型假设→符号说明→模型建立与求解→模型检验→模型改进与推广→模型优缺点→参考文献+附录
□ 正文 30 页左右、尽量 30 页内，无目录
```

### 第四检：全局格式（书 §7.2）
```
□ 页面：A4；上下 2.5cm、左右 2.5cm（左右对称）
□ **页眉页脚：页眉留空（无文字、无横线、无章节名/页码）；页码为阿拉伯数字、居中于页脚；正文与附录全部页面统一**
□ **章节编号：一级标题用中文数字（一、二、三…，如"一、问题重述"）；二级可用阿拉伯（1.1）；全文无阿拉伯一级编号**
□ 字体：中文宋体；英文/数字/公式 Times New Roman；题目16号加粗居中/一级14号加粗居中/二三级12号加粗左对齐/正文12号
□ 行距：全文单倍行距；正文首行缩进 2 字符；禁止大段空白行
□ 表格：一律三线表（无竖线、无彩色填充、无复杂边框）；表标题在上；编号连续
□ **表格宽度不超版心**：宽表用 \small + p{宽度} 列换行（或 \resizebox{\textwidth}{!}{}）；表格居中、不超出右边界
□ 图片：原创高清（非截图）、无水印、无模糊拉伸、≥300DPI、宽度 8-16cm、图内标注中文（配 SimHei 无乱码）；**图标题在上**（图序号+图名在图片上方、中文图题）；每图配专业图注
□ 公式：独占一行居中、关键公式编号右对齐、编号连续；符号与符号说明表一致
□ 图表：正文必须引用每张图/每个表，图文一一对应
□ 分页：图表不跨页割裂；标题后至少跟 2 行正文；无单页仅几行文字
```

### 第五检：PDF/tex 工程检测
```
□ paper/main.tex 存在且完整（documentclass、packages、\input 各章节、\end{document}）
□ paper/sections/ 下 12 模块对应 .tex 文件齐全
□ compile.bat 存在；xelatex 编译无 Error（仅 Warning 可接受）；main.pdf 生成且 >50KB
□ **xelatex 日志 Overfull \hbox 为 0**（尤其表格超宽；允许用 \emergencystretch 缓解散文长公式溢出）
□ **图表编号引用审计**：正文"表X/图X"引用与实际编号一致（新增/删除图表后必须全文核对，建议用 \label/\ref）
□ PDF 打开检查：所有页面正常、无缺页、公式正确渲染、图片清晰嵌入、无文字重叠越界；表格居中
□ 正文（题目→摘要→…→参考文献）≤30 页、无目录；附录不计页数
□ 附录：数据/代码/推导/AI使用说明 四块齐全；代码附录可运行
```

### 第六检：附录完整性（附录四件套，对齐优秀论文 P24-37）
```
□ **附录编号用阿拉伯数字（附录1、附录2…），禁止用字母（附录A/B/C）**
□ 附录有表1「支撑文件目录」（code/ 每个脚本一行：文件名→功能→对应附录）
□ 附录有表2「附录目录」（附录编号→名称）
□ 代码按问拆分，每个附录 = 对应 code/*.py 的完整全文（lstlisting），非关键片段
□ 每个代码附录开头有"对应正文第 X 节/表 X"说明
□ 附录开头有运行环境 + 一键复现说明（Python 版本/依赖/requirements）
□ 附录含 AI 使用说明（2026 强制）
□ 附录代码与 code/ 实际文件一致（防止"附录代码跑不出正文结果"）
```

### 第七检：AI 编辑痕迹（写作纪律，全文扫雷）
```
□ 无"编辑说明/占位/模板"式文字：单独成页、占位、待插入、待完善、同上结构、用于直接展示 等
□ 表格/图注补充说明用标准"注：…"，无"本列用于/读者可"设计辩护语气
□ 附录/章节引导语为自然学术衔接句，无模板占位符（{XXX}、同上、见附录N）原样残留
```

## 检测结果报告格式

```markdown
# 格式检测报告

## 检测时间：YYYY-MM-DD HH:MM

## 检测结果总览
- 总检测项：X 项
- 通过：X 项
- 不通过：X 项
- 状态：PASS / FAIL / BLOCK

## 不通过项详情
| 编号 | 检测类别 | 问题描述 | 严重程度(high/mid/low) | 修正建议 |

## 最终判定
- [ ] 全部通过，可输出论文
- [ ] 存在不通过项，需修正后重新检测
```

**严重程度规则**：`high` → verdict=`block`（暂停，用户介入）；`mid`/`low` → 定向修正后重检。
