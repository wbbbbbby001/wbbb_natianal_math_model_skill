# 光谱/周期信号处理专项方法论与坑（物理机理+数据处理类通用）

> 依据：2025 B 题（碳化硅/硅外延层厚度的红外干涉反演）实战复盘。红外干涉光谱 = "周期性振荡信号" + "慢变包络"，周期反演参数（厚度/膜厚/间距/层厚）是数据题高频考点。本文档沉淀的坑与方法可迁移到一切"从周期性光谱/信号反演物理参数"的题目（薄膜测厚、干涉测量、光栅、回波测距等）。

---

## 一、五个必踩的坑（先看这个，省半天调试）

### 坑1：包络滤波窗宽必须 ≥ 3~8 个信号周期
- **现象**：用固定窗长（如 501 点）的 Savitzky–Golay 提取背景时，若窗长≈信号周期量级，滤波器会**部分跟随条纹本身**，导致振荡分量周期被扭曲，FFT 主频偏到错误值（实测周期从正确 416 被污染成 208，厚度差一倍）。
- **规则**：包络窗宽 ≥ 3~8 个信号周期；先用多项式基线粗估周期，再据此设 SG 窗宽（`wl = int(8 * period_pts) | 1`）。最稳妥的做法是"多项式基线 + 宽窗 SG 取平均"。
- **自检**：改窗宽 0.5×/1×/2×，若 FFT 主频跳变 → 包络污染，须加大窗宽。

### 坑2：FFT 主频重建公式写反
- **错误**：`f0 = k * d_nu / n`（得到的是 $k\cdot\Delta\nu_s/N$，数量级差 $1/\Delta\nu_s^2$ 倍）
- **正确**：频率分辨率 $\Delta f = 1/(N\cdot\Delta\nu_s)$，主频 $f_0 = k/(N\cdot\Delta\nu_s)$，周期 $\Delta\nu=1/f_0$。抛物线插值后 $k$ 取浮点值代入。
- **自检**：对已知周期信号（合成/真值）跑通一遍，误差应 <1e-3。

### 坑3：相位公式单位一致性
- **现象**：$\varphi=4\pi n_1 d\cos\theta_1\,\nu$ 中，若 $d$ 用 $\mu$m、$\nu$ 用 $\mathrm{cm^{-1}}$，直接相乘会让相位以错误频率振荡（超 Nyquist 混叠，拟合全废）。
- **规则**：$\nu$ 用 $\mathrm{cm^{-1}}$ 时，$d$ 必须换算成 cm（$\mu$m$\times10^{-4}$）；反演时 $d[\mathrm{cm}] = 1/(2n\Delta\nu\cos\theta_1)$，再 $\times10^4$ 得 $\mu$m。
- **自检**：周期 $\Delta\nu \approx 1/(2nd\cos\theta_1)$ 量级应在 $10\sim1000\ \mathrm{cm^{-1}}$，若算出 $10^{-6}$ 或 $10^6$ 就是单位错了。

### 坑4：弱信号峰值检测误判
- **现象**：振幅只有背景 1% 的条纹上，`find_peaks` 会把噪声峰也检出来，峰间距变成真实周期一半或更乱。
- **规则**：加 `prominence`（如 0.2×振幅标准差）与 `distance`（≥0.45×预估周期点数）双重约束；更稳健的做法是**极值间距法取极大+极小交替间距 = 半周期，再 ×2**，并对间距做稳健均值（剔除离群）。
- **自检**：检测出的峰数 ≈ 窗口宽度/周期，相差 >1.5 倍即误检。

### 坑5：包络去除不足导致 FFT 假谐波
- **现象**：背景去不干净时，慢变包络在 FFT 里产生低频大峰，掩盖真实基频，甚至让"二次谐波比 H2"失真。
- **规则**：先去包络再做 FFT/谐波分析；H2 这类"多光束/非线性判据"必须在干净的振荡分量上算。

## 二、三方法周期估计交叉验证（推荐框架）

| 方法 | 原理 | 优点 | 弱点 |
|------|------|------|------|
| FFT 主频 | 频谱主峰（抛物线插值细化） | 全局稳健、抗噪 | 条纹数少时受分档量化影响 |
| 希尔伯特相位法 | 解析信号相位 $\Phi=4\pi n_g d\cos\theta_1\nu+\Phi_0$ 线性拟合斜率 | 对包络最稳健、分辨率连续 | 需解缠绕，两端边缘效应 |
| 极值间距法 | 相邻极大/极小间距=半周期，×2 | 直观、物理透明 | 弱信号易误检（需 prominence/distance） |

**融合**：三法独立反演取均值 $\bar d$、标准差 $\sigma_d$；方法间极差 <2% 视为一致。**相位法是弱包络变化场景的首选**——它利用全部样本相位信息，不受振幅调制影响。

## 三、多光束/高阶效应判据（光学机理题）

- **必要可观测条件**：界面反射率乘积 $s=\sqrt{R_1R_2}$ 不可忽略（$s\ge1\%$ 量级可观测）。$R_1$ 由 Fresnel 公式（s/p 平均）定，$R_2$ 由条纹对比度反演：$B\approx2(1-R_1)\sqrt{R_1R_2}$。
- **二次谐波比**：$H_2=|F(2f_0)|/|F(f_0)|$，多光束越强 H2 越大；纯余弦时 ≈0。**必须在去包络后的振荡分量上计算**。
- **共振峰位置对高阶效应稳健**：多光束/非线性不改变共振条件（$2nd\cos\theta_1\nu_m=m$），因此**用基频方法（FFT/相位/极值）反演参数，天然规避高阶污染**；需要"消除高阶影响"时，优先用基频稳健法而非硬拟合高阶模型。
- **判定组合**：必要条件值 $s$ + 谐波比 $H_2$ + 模型对比（两光束 vs Airy 拟合 R²），三重证据比单一指标可靠。

## 四、物理机理题通用流程（周期反演类）

```
1. 从题面提取"周期信号 ↔ 待反演参数"的解析关系（推导闭式反演式，含色散/群速度修正）
2. 数据预处理：剔除吸收带/异常区 → 去包络（窗宽≥8周期）→ 振荡分量
3. 三方法周期估计 + 交叉验证
4. 反演参数 + 色散/单位修正 + 双通道（多入射角/多通道）一致性
5. 灵敏度（理论解析 vs 数值扰动）+ 蒙特卡洛加噪 + 物理合理性验证
```

> 配套：反演式含色散时用**群速度/群折射率**（$n_g=n+\nu\,dn/d\nu$）而非相速度/相折射率；可识别性讨论（周期只确定 $n\cdot d$ 乘积，$n$ 必须由文献/独立测量给出）。
