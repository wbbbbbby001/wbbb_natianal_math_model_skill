# 国赛官方评审标准与获奖底层逻辑

> 权威口径：《2026 国赛三天速成国奖》宝书 §1.5 / §8 / §7.5.1

## 一、官方评审标准（满分 100 分）

| 评审维度 | 分值 | 核心要求 | 评委关注点 |
|---------|------|---------|-----------|
| 假设的合理性 | 20 分 | 假设贴合实际、不脱离问题、必要且充分 | 假设是否严谨、有无理想化过头 |
| 建模的创造性 | 30 分 | 模型针对性强、有改进、不堆砌、有创新 | 模型是否适配本题、有无创新改进 |
| 结果的正确性 | 30 分 | 结果可信、可复现、数值合理、检验充分 | 误差、灵敏度、稳健性是否完整 |
| 表述的清晰性 | 20 分 | 结构完整、逻辑通顺、图表规范、排版美观 | 摘要、符号、公式、图表是否专业 |

**注意**：国赛重点是"解决问题"，创新只是加分项。结果正确、逻辑严谨的论文即使模型朴素也能获奖；模型堆砌、脱离赛题反而扣分。

## 二、评委评审潜规则

```
评审流程：1.先看摘要 → 2.再看模型 → 3.再看结果 → 4.最后看格式
初审阶段（5-10 分钟）：
- 摘要差 → 直接淘汰（不进终审）
- 模型是否合理、有无创新、有无检验
- 数值是否合理、图表是否清晰
- 匿名、排版、符号、公式是否规范
```

## 三、六大获奖底层思维

| 思维 | 核心原则 |
|------|---------|
| 问题思维 | 模型为问题服务，绝不堆砌高级模型 |
| 检验思维 | 所有模型必须做灵敏度、误差、稳健性检验 |
| 规范思维 | 符号、公式、图表、排版严格标准化 |
| 团队思维 | 建模/编程/写作三岗分明、无缝衔接 |
| 落地思维 | 结果可解释、可复现、可应用，不做空中楼阁 |
| 合规思维 | 匿名、查重、提交时间绝对不踩红线 |

## 四、高频致命扣分点（书 §7.5.1）

- 摘要无量化结果、逻辑混乱、空话泛滥
- 缺失误差分析、灵敏度、稳健性任意一项检验
- 图表无编号、无标题、无单位，图文不符、截图模糊
- 公式错乱、符号不统一、量纲缺失、编号混乱
- 大段照搬原题、网络内容，重复率超标
- 代码缺失、无注释、无法复现求解结果
- 匿名不彻底，残留个人/学校信息
- 模型堆砌、与赛题场景严重脱节
- 正文无数据、无推导、无结果，内容单薄

## 五、奖项与选拔（概览）

- 赛区一/二/三等奖：获奖比例一般不超过参赛队数 1/3；
- 全国一等奖约 1%、全国二等奖约 5%；
- 采用"地方初评 — 全国终审"双层机制；赛区报送全国前须过相似度查证（≥25% 原则上不得报送）。

## 六、A/B/C 三题定位速记

| 题目 | 难度 | 核心 | 适合人群 |
|------|------|------|---------|
| A 题（硬核机理） | 最高 | 物理/工程机理+微分方程+复杂优化 | 数学强、推导强、理论扎实 |
| B 题（开放综合） | 中等 | 社会/管理/调度+多元模型+综合决策 | 均衡型、写作强、逻辑强 |
| C 题（数据统计） | 中等 | 数据处理+机器学习+优化决策 | 编程强、数据分析强、经管背景 |

选题总原则：**不硬冲 A 题、不强行做不擅长方向；数据可控、公开易获取优先；新手优先 B/C**。
