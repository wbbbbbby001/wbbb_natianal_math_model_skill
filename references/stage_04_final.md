# 阶段4：终审与提交

> 目标：五步终审 + 合规清单 + 打包提交。建议耗时 2-6h（需预留 ≥1h 做提交）。

## 入口条件

- `final_paper.md` + `paper/main.pdf` 已产出并通过阶段3 门禁。

## 加载

- `references/format_checker.md`（终审清单）
- `references/rules_2026.md`（当届规则：时间轴/MD5/匿名/查重/AI 披露）

## 任务

1. **五步终审**（`references/paper_structure.md` §四）：
   a. 内容定稿：所有子问题均已求解，逻辑闭环、无遗漏；
   b. 格式统一：字体/行距/缩进/标题层级/图表格式统一；**页眉留空（无文字/横线）；页码阿拉伯数字居中于页脚；一级标题中文数字（一、二、三…）；附录数字编号（附录1、附录2…，无字母）**；
   c. 细节规范：公式、图表编号连续有序，量纲、标注完整；
   d. 匿名合规：全文排查隐私信息（含文件名、文档属性、页眉页脚）；
   e. 导出预览：PDF 排版/分页/清晰度检查，修正错乱。
2. **合规清单**（任一不通过 → block）：
   - 匿名：无姓名/学校/学号/战队名/校徽/参赛编号；
   - 查重：问题重述自主改写、模型原理自主表述、图表代码原创、重复率目标 ≤20%；
   - AI 披露：附录4「AI 使用说明」存在（工具名/版本/开发方/使用日期/使用环节/用途），核心建模与推导由队伍完成；
   - 格式：按官方规范，PDF 提交；**页眉留空、页码页脚居中阿拉伯数字、一级标题中文数字、附录数字编号**。
3. **L2 一致性终检**：全文数值/模型/创新点与 state 一致。
4. **打包提交**（按 `rules_2026.md`；**工作流不自动生成 MD5**）：
   - 论文 PDF（匿名版）复制为提交件；
   - 支撑材料 ZIP/RAR：code/、data/、figures/、AI 使用说明；
   - **MD5 校验码由队伍在官方系统上传时自行生成**（论文+支撑材料分别），工作流不预生成记录；
   - **提前 1 小时完成提交**，避开网络拥堵；提交后截图留证、本地备份。
   - 参考当届官方评阅要点核对解题覆盖（示例非规则，不硬编码具体题目）。

## 出口门禁

- [ ] 五步终审全部通过
- [ ] 合规清单全部通过（匿名/查重/AI 披露/格式）
- [ ] L2 一致性通过
- [ ] 提交包就绪：论文 PDF + 支撑材料 ZIP + 备份（MD5 由队伍按官方系统自行生成）

**verdict**：任一项违规 → `block`（暂停，用户介入修正）；全部通过 → `pass`（完成交付）。

## 产出

- `提交包/`（或按当届要求命名）：论文 PDF、支撑材料 ZIP、AI 使用说明（**不生成 MD5 记录**，由队伍上传时自行生成）
- `format_check_report.md`（终版，全部 PASS）
- state 更新：`compliance`、`scores.stage_4`、`current_stage=completed`。
