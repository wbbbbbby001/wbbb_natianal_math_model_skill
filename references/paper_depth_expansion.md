# 论文正文深度扩充清单（治"正文太薄"）

> 依据：2025 B 题（碳化硅外延层厚度）实战复盘。首次成稿正文仅 14 页，按本清单扩充后达到 25 页（在 2026 年"正文≤30 页"上限内），L1 深度维度从 7 提升到 9。
> 核心结论：**正文页数下限是硬门禁，不是建议**。12 模块齐全 + format_check PASS 只代表"合规"，不代表"有深度"；单薄论文（12-14 页）与优秀论文（23-30 页）的差距全部来自推导展开与呈现结构（见 `paper_depth_guide.md`）。

---

## 一、正文页数目标（standard 模式硬门禁）

| 模式 | 正文页数（题目→摘要→…→参考文献） |
|------|----------------------------------|
| standard（>48h） | **必须 >23 页（即 ≥24，目标 24-28 页，上限 30 页）** |
| standard+fast（12-48h） | ≥16 页，只保核心章节 |
| fast（<12h） | ≥12 页，跳阶段0-2 建模细节 |

**低于下限 → 定向精修（refine）**，按下方"深度要素清单"逐项补齐，禁止靠调大行距/字号/留白凑页数。
**口径变更（实战复盘）**：问题重述按"背景分段展开 + 已知条件与数据说明 + 逐问重述"、问题分析按"数据特征 + **逐问单独分析** + 重难点 + 选型 + 技术路线"扩写后（各占 1.5-2 页 / 2.5-3 页），仅这两个模块就比旧版多出 2-3 页，因此 standard 下限从 20 页提高到 24 页（>23）。**正文页数是否真的达标，必须用 `scripts/depth_check.py` 对编译出的 main.pdf 复核**（脚本通过"运行环境说明"字样正确定位附录起点，正文=附录前一页；注意勿把附录误计入正文）。

## 二、深度要素清单（逐项核对，全部达标才算"有深度"）

### A. 问题重述（1.5-2 页，扩写标准）
- [ ] **问题背景分段展开（2-3 段，不抄原题）**：第一段行业/材料背景与工程价值（如材料特性、应用领域）；第二段测量方法原理与为何重要（无损、可批量）；第三段本题两大物理挑战（色散、多光束）与研究意义
- [ ] **已知条件与数据说明**：题目自带数据的来源、字段、量纲、采样范围与分组（如不同入射角/不同材料），独立成小节，配数据条目清单
- [ ] **需要解决的问题（逐问重述）**：按问题一/二/三分点，每问写清"目标定位 + 需要做什么 + 输入输出"，用自己的话改写、明确各问的递进关系，不照抄原题
- [ ] **测量/生产原理示意图**：原创绘制（不得截图原题图）

### B. 问题分析（2.5-3 页，扩写标准）
- [ ] **数据特征统计表**：对题目自带数据做分区分组统计（如光谱分波段均值/标准差、分布区间），用三线表呈现
- [ ] **数据初步判读表**：把关键特征（周期/振幅/谐波/趋势）量化成一张表，并给出物理含义推断
- [ ] **逐问单独分析（问题一分析 / 问题二分析 / …问题N分析）**：对每一问各写一段独立分析，含四要素——①该问的目标定位（机理建模/算法反演/评价决策/预测…）；②该问要解决的核心与数据特征约束（如弱对比度、吸收带、异常值）；③针对该问的建模/算法方向与难点；④该问的创新切入点（标注五大路径之一）
- [ ] **技术路线流程图**：原创绘制（matplotlib 方框+箭头或类似），覆盖"数据→预处理→建模→求解→检验→结论"全链路；**必须为每个子问题单独设阶段框**（如"问题一相关性+回归 / 问题二分组+优化 / 问题三… / 问题四…"），不得只画某一问的流程冒充整体流程图（实战教训：Q1 流程图被用作"整体建模流程"，因缺 Q2/Q3/Q4 被判"不完整"）；分问流程子图另画，与整体流程区分；**直接复用 `references/workflow_figure.md` 的 v4 模板函数 `draw_pipeline_flowchart()`**（面板容器+编号+每问产出标注+白底标签防遮挡+图例，N 问自适应），避免从零画且踩文字遮挡的坑
- [ ] 解题重难点逐条拆解 + 模型选型依据与创新切入点（总体）

### B. 每问模型建立及求解（每问 4-6 页）
- [ ] **推导逐步展开**：每个关键公式前有文字铺垫，推导步骤 ≥6 步，禁止"直接给最终公式"（分布建模→闭式→解释，见 `paper_depth_guide.md`）
- [ ] **算法伪代码**：核心求解流程用 `algorithm`/`algorithmic` 环境呈现（输入/预处理/分步求解/输出/检验），尤其算法题必配。**中文化口径**：算法标题 `\caption{}` 与 `\State` 正文用中文；`\Require`/`\Ensure`/`\If`/`\ElsIf`/`\Else`/`\Return` 等关键字保持英文（标准伪代码约定）；**不要用 `\algrenewcommand`/`\algrenewtext` 重定义这些关键字**——嵌套 if/for 会触发 `\ALG@cmd@N@... undefined` 报错
- [ ] **至少 2 张支撑图**：除原理图外，给"实测曲线+模型/包络叠加""频谱/相位/特征图"等过程图
- [ ] **全量结果表**：不只给最优值，给"方法×晶圆/方案"全量矩阵表 + 不确定性 + 判定列
- [ ] **结果解读**：每个表/图配 ≥2 句量化解读（趋势/原因/物理含义），拒绝"由上表可见"空话

### C. 灵敏度分析（独立章节，1-2 页）
- [ ] 核心参数（模型输入）±扰动结果表 + 影响图
- [ ] **理论-数值交叉验证**：对闭式反演式求解析灵敏度，与数值扰动结果对比，证明分析正确（如 $\delta d/d=-\delta n/n$）

### D. 模型检验（1.5-2.5 页）
- [ ] **全量结果汇总表**：所有子问题最终结果 + 方法间极差 + 噪声不确定度 + 判定列，一张表收口
- [ ] 误差分析（R²/RMSE/DW）+ 稳健性（替换算法/加噪/双测量通道/区间伸缩）逐项

### E. 结果讨论与物理合理性（0.5-1 页）
- [ ] 结果与行业/物理典型量级对比验证（如外延层厚度与功率器件典型值）
- [ ] 跨子问题结果的一致性讨论（双通道/多方法/多材料对比）

### F. 三问收尾
- [ ] 模型评价分问写（每问优点+缺点，见 `paper_structure.md`）
- [ ] 改进方向务实（短期可做/长期） + 推广价值具体到同类场景

## 三、常见"薄"的五个病灶（对号入座）

| 病灶 | 表现 | 补齐动作 |
|------|------|---------|
| 推导跳跃 | 每问只有 2-3 个公式 | 展开到 ≥6 步，每步配文字与公式编号 |
| 只有最优值 | 决策/结果类只给最终数 | 补全量方案/方法×情形矩阵表 |
| 缺过程图 | 只有原理图 | 补频谱/相位/拟合对比/分布图（2 张以上/问） |
| 灵敏度是空壳 | 只有一句话"结果稳健" | 补扰动表 + 影响图 + 理论验证 |
| 结果无讨论 | 算完就结束 | 补物理合理性 + 跨问一致性讨论 |

## 四、落地检查命令

```bash
# 深度硬检测（正文页数 + 深度要素），正文 <20 页或要素缺失 → REFINE
python scripts/depth_check.py final_paper.md paper/main.tex paper/main.pdf
```

> 与 `format_check.py` 的关系：format_check 管"合规"（结构/格式/匿名/附录），depth_check 管"深度"（页数/推导/图表/检验）。两关都要过。
