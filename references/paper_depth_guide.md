# 国赛优秀论文深度与篇幅标准

> 依据：2024 国赛 B 题官方优秀论文（生产过程中的决策问题，R/Python 实现）逐页精读提炼。
> 用途：建模手（阶段1）与论文手（阶段3）的**推导深度**与**结构呈现**对齐标杆，避免"结论式写作"导致正文单薄（优秀论文正文 24 页 vs 单薄论文 13 页的差距全部来自推导过程与呈现结构）。

---

## 一、核心差距的根源（优秀论文 vs 单薄论文）

| 维度 | 单薄论文（常见问题） | 优秀论文 |
|------|--------------------|---------|
| 模型建立 | 直接给最终公式，推导过程省略 | **逐步推导**：统计分布→闭式/递推表达式→每步有文字解释 |
| 决策类题目 | 只给最优方案 | 列出**全部决策方案**及各自期望表达式，再给全量结果表 |
| 多级/网络类 | 简化结构、只做单级 | 完整状态-决策模型，中间节点同样建模（如半成品两级拆解） |
| 不确定性 | 参数点估计代入 | 贝叶斯后验/区间/分布积分，量化误差影响 |
| 结果呈现 | 只列最优数值 | **全量数值表**（如 16 方案 × 6 情形）+ 判据解释 |
| 结构 | 检验/评价合并、无流程图 | 灵敏度独立成章、模型评价分问写、问题重述配流程图 |
| 附录 | 仅文字指向代码 | **内嵌全量可运行代码**（带注释+运行环境） |

## 二、四类高频题型的"显式推导"深度标准（从 2024B 提炼）

### 2.1 抽样检测 / 假设检验类（对应 2024B 问题一）
优秀论文必含三步推导，缺一不可：
1. **检验统计量与拒绝域**：构造 $X\sim\mathrm{Bin}(n,p)$ 或 $\bar X$ 渐进正态，写出拒绝域的临界值表达式；
2. **功效函数 $K(n,p)$**：显式写出不同真实次品率下的拒收概率；
3. **样本量决策函数**：把"检测次数尽可能少"建模为**检测成本 × 检验效果的权衡**
   $$g(n)=w_1 c n-w_2\int_{\Theta}K(n,p)f(p)\,dp,\qquad n^*=\arg\max g(n)$$
   （$c$ 单件检测成本，$w_1,w_2$ 权重，$f(p)$ 次品率先验，常取均匀分布；也可同时给出双错误率约束法作对照。）
- **口径提示**：只给"固定功效约束下的最小 n"（如 n=109）不如"成本×功效权衡 n"贴近题意，建议两法并呈、互相印证。

### 2.2 多环节决策 / 生产决策类（对应 2024B 问题二）
优秀论文的核心是**显式期望推导**，而非枚举代码：
1. 用**二项分布 + 几何分布**推导"产出第 1 个合格件所需的期望次数"：
   $$E[N]=\frac{1}{1-p}\ (\text{零配件}),\qquad E[N]=\frac{1}{(1-p_1)(1-p_2)(1-p_3)}\ (\text{成品})$$
2. 每个决策方案给出**期望成本/利润的闭式表达式**，列出**全部方案表达式表**（如 16 方案）；
3. **拆解/回收类分支**按**互斥情形分类**逐个推导（如 5 类：全部合格 / 装配错 / 子件A坏 / 子件B坏 / 双坏），每类给概率 + 条件成本；
4. **防循环假设**必须显式声明（如"拆解出的未检子件重新检测后方可回用"），避免期望无限循环。

### 2.3 多级网络 / 多阶段决策类（对应 2024B 问题三）
两种高质量框架任选其一（或并用）：
- **A. 状态-决策模型 + 动态规划**（官方优秀论文采用）：
  - 状态变量含**检测态 d、质量态 q、拆解态 r**：$S=(d,q,r)$；
  - 成本函数 $C(a)=C_{\text{purchase}}+C_{\text{inspect}}+C_{\text{assemble}}+C_{\text{disassemble}}$；
  - 收益函数 $R(S,a)=R_{\text{sales}}+R_{\text{recycle}}$（拆解回收合格子件收益）；
  - 递推 $V(S,a)=R(S,a)-C(a)+E[V(S_{t+1},a_{t+1})]$，记忆化递归求解。
- **B. 反向期望递推**（本 skill 已内置）：节点"单位合格件成本 $C_v$ + 合格概率 $g_v$"自下而上传递，复杂度随节点数线性。
- **深度要点**：中间节点（半成品）同样要建模——**允许不合格半成品拆解回收零件**，回收收益 = 子件价值 − 拆解费；注明"合格子件不继续拆解（回收价值更高）"的决策理由。

### 2.4 参数不确定性 / 稳健性类（对应 2024B 问题四）
- **首选：贝叶斯共轭先验 + 解析积分**（官方优秀论文采用）：
  - 二项分布的共轭先验 $\mathrm{Beta}(\alpha,\beta)$，后验 $\mathrm{Beta}(\alpha+k,\beta+n-k)$；
  - 未检件是否为次品 $X$ 的分布对 $p$ 的不确定性**积分**得到 $P(X=1)=p_0$；
  - 目标利润对后验分布**解析积分** $E[h(p_1,p_2,p_3)]=\iiint h(\cdot)\varphi_1\varphi_2\varphi_3\,dp$；
  - 附**先验超参数灵敏度**（$\alpha,\beta\in\{1,\dots,10\}$ 对结果影响小）。
- 备选：蒙特卡洛参数抽样 + 决策频率/失效概率统计（本 skill 已内置），结果与贝叶斯互为印证。

## 三、结构与呈现标准（对齐优秀论文）

| 模块 | 优秀论文做法 | 本 skill 执行要求 |
|------|-------------|-----------------|
| 问题重述 | 背景 + 已知条件 + **原创生产/流程示意图**（图1） | 论文手必须在问题重述中插入原创流程图 |
| 模型假设 | 数量可少（2-3 条）但**每条附详细说明**（依据+影响） | 假设=内容+依据+对模型的影响，禁止空话 |
| 章节组织 | **每问独立成章**（"问题一模型建立及求解"独立一级标题） | 论文手不再把所有问题塞进一个"模型建立与求解"大章 |
| 结果呈现 | **每问标配结果表**：方案编号表 + 全量表达式表 + 全量结果矩阵 + 最优决策表（表2-5）；统计类两情形对照总结表（表1）；问题四最优决策标注"与确定性最优是否一致"（表8） | 决策/枚举/统计类按此给表，非只给数值 |
| 模型建立与求解 | 每问"适配分析 → 逐步推导 → 算法 → 全量结果表" | 推导过程**不省略**；决策类给**全部方案表** |
| 灵敏度分析 | **独立成章**（先验超参数/关键参数扰动 + 图） | 模型检验中独立小节，篇幅≥检验的 1/3 |
| 模型评价 | **分问写**（问题一/二/三各列优点+缺点） | 不再合并写，逐问给出优缺点 |
| 参考文献 | 引用与模型方法强相关（数理统计/DP/贝叶斯） | 5-10 条，含支撑模型推导的教材/论文 |
| 附录 | **附录四件套**：支撑文件目录表 + 附录目录表 + **分问全量代码**（code/ 每问脚本完整贴入）+ 运行环境说明 | 详见 `appendix_guide.md`，禁止只贴关键片段 |

## 四、篇幅参考

- 正文（题目→摘要→…→参考文献）：**≤30 页（2026 硬性上限）**；standard 模式**必须 >23 页（即 ≥24，目标 24-28）**——问题重述（背景分段展开+数据说明+逐问重述，1.5-2 页）与问题分析（数据特征+逐问单独分析+重难点+选型+技术路线，2.5-3 页）扩写后，仅此两模块就贡献 4-5 页；单薄论文常因省略推导只有 12-14 页；
- 正文做足推导过程与全量结果表，**不贴长代码**——所有代码细节下沉附录；
- 附录代码：**不计页数**，把 `code/` 全部脚本分问完整贴入（详见 `appendix_guide.md`）；
- 摘要仍按官方规范 **800-1000 字**（注意：2024B 优秀论文摘要 ~400 字属个别风格，官方规范要求 800-1000，从规范）。

## 五、落地检查清单（阶段1/3 出口自检）

- [ ] **正文页数下限**：standard 模式正文（题目→摘要→…→参考文献）**>23 页（即 ≥24）**、目标 24-28、上限 30；低于下限按 `references/paper_depth_expansion.md` 深度要素清单定向扩充（防"合规但太薄"），并跑 `scripts/depth_check.py` 验证——注意脚本靠附录"运行环境说明"字样定位附录起点，附录标题勿写"运行环境"，否则正文页数虚高
- [ ] 每问推导：≥1 个统计分布建模 + 闭式/递推表达式，无"直接给公式"跳跃

- [ ] 结构：问题重述有流程图；**每问独立成章**；灵敏度分析独立成节；模型评价分问写
