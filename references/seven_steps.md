# 国赛全流程标准建模体系

> 权威口径：《2026 国赛三天速成国奖》宝书 §2。国赛 99% 的题目可归入四大核心题型。

## 一、标准七步解题法（书 §2.1）

```
第一步：模型准备   → 精读题目，圈出已知条件、决策目标、约束条件；明确题型；确定数据需求
第二步：模型假设   → 对复杂问题简化、抓主要矛盾；3-5 条，合理、必要、明确、可验证
第三步：符号说明   → 统一变量符号/单位/含义，三线表呈现
第四步：模型建立   → 按题型对应模型，不堆砌、不盲目求难；公式规范、创新点足、推导严谨
第五步：模型求解   → 选用合适算法与软件（MATLAB/Python/Lingo），给关键步骤、核心代码、结果；表格+图形呈现
第六步：模型检验   → 误差分析、灵敏度分析、稳健性分析，检验支撑结论
第七步：改进推广   → 客观评价不足、给改进方向、说明适用范围与推广价值
```

## 二、四大核心题型判定（书 §2.2）

| 题型 | 核心诉求 | 出现频率 | 对应题号 |
|------|---------|---------|---------|
| 优化类 | 求最优决策（成本最低/收益最大/效率最高） | 100%（必考题） | A/B/C 均有 |
| 评价类 | 分优劣、做评判（多指标→综合评分→排序） | 高频 | B/C 为主 |
| 预测类 | 推未来、估数值（时序/回归/机器学习） | 高频 | B/C 为主 |
| 机理分析类 | 释规律、建物理方程（微分方程/动力学） | 高频（A 题专属） | A 题必考 |

## 三、各题型标准建模全流程

### 优化类（书 §2.3，必考，须熟练默写）
```
1. 确定优化目标：成本最小/收益最大/效率最高
2. 提取决策变量：数量、时间、路径、配比等可控量
3. 梳理约束条件：资源、产能、需求、物理限制
4. 构建规划模型：线性→线性规划；非线性→非线性规划；整数/0-1→整数规划；多目标→多目标规划；分阶段→动态规划
5. 选择求解算法：凸问题→梯度法/内点法；非凸/复杂→遗传算法/粒子群/模拟退火
6. 结果分析 + 灵敏度检验
```

**决策/抽样类子类的显式推导要点（对齐优秀论文，见 `paper_depth_guide.md`）**：
```
● 抽样检测类：统计分布建模 → 拒绝域/临界值 → 功效函数 K(n,p) → 决策函数 g(n)=w₁cn−w₂∫K(n,p)f(p)dp 求最小样本量
● 多环节决策类：枚举全部决策方案 → 用二项/几何分布推导每方案"期望成本/利润"闭式 → 全量结果表再取最优
● 多级网络决策类：状态-决策模型(检测态d/质量态q/拆解态r) + 动态规划(记忆化)，或节点级"单位合格件成本+合格概率"反向递推；中间节点(半成品)同样建模，允许拆解回收
● 防循环假设必须显式声明（如"拆解出的未检子件重新检测后方可回用"），避免期望无限循环
```

### 评价类（书 §2.4）
```
1. 构建评价指标体系（全面、独立、可量化、可获取）
2. 指标预处理（正向化、无量纲化、去异常值）
3. 确定权重：主观 AHP（需一致性检验）/ 客观熵权法 / 组合 AHP-熵权（高分首选）
4. 综合评价模型：TOPSIS、模糊综合评价、DEA、灰色关联
5. 结果排序 + 稳健性检验
```

### 预测类（书 §2.5）
```
1. 明确预测目标与周期
2. 数据预处理（缺失填充、异常剔除、平稳化）
3. 选模型：小样本→GM(1,1)；时序→ARIMA/指数平滑；回归→多元/Lasso/岭；机器学习→RF/XGBoost
4. 模型检验：R²、残差检验、MAPE/RMSE
5. 区间预测 + 结果分析
```

### 机理分析类（书 §2.6）
```
1. 物理/工程背景分析（力学、热传、流体、运动学、动力学）
2. 基本定律提取（牛顿定律、能量守恒、质量守恒、传热定律）
3. 建立微分/动力学方程（常微分、偏微分、方程组）
4. 方程求解（解析解/数值解：龙格-库塔、有限差分等）
5. 参数分析 + 灵敏度检验
```

### 数据处理与挖掘类（书 §2.7，C 题高频）
```
1. 数据探查 EDA（描述统计、分布、缺失、异常）
2. 数据清洗（缺失<5%均值/中位数；5%-30%插值；>30%预测填充；异常 3σ/箱线图/LOF）
3. 数据变换（标准化、归一化、编码、离散化）
4. 特征工程（特征选择、PCA 降维、相关性分析）
5. 建模分析（聚类、分类、关联规则、判别分析）
```

## 四、题型区分总述

- 优化类：核心诉求——求最优决策；
- 评价类：核心诉求——分优劣、做评判；
- 预测类：核心诉求——推未来、估数值；
- 机理分析类：核心诉求——释规律、建物理方程。
