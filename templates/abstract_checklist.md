# 摘要5审自查清单

> 权威口径：《2026 国赛三天速成国奖》宝书 §7.3.3 / §7.3.5 / §8.1。摘要是国赛评审第一眼、第一关、第一权重内容，初审 5-10 分钟决定能否进终审，**摘要占总成绩约 40%**。

---

## 第1审：字数与篇幅合规

| 检查项 | 标准 | 自检 |
|--------|------|------|
| 总字数 | **800-1000 字** | □ 通过 / □ 不通过（实际 __ 字） |
| 版面 | 单页内，占 3/4 或 4/5 最佳 | □ 通过 / □ 不通过 |
| 段落 | 分段合理不零散 | □ 通过 / □ 不通过 |

## 第2审：结构合规（严格三段式）

| 段落 | 内容 | 建议字数 | 自检 |
|------|------|---------|------|
| 第一段（虎头） | 行业背景价值 → 技术现实痛点 → 本文建模解决方案 | 150-200 字 | □ 完整 |
| 第二段（猪肚） | 数据预处理 + 逐问[模型+算法+创新+量化结果] | 450-550 字 | □ 完整 |
| 第三段（豹尾） | 创新点总结 + 检验(灵敏度/稳健性) + 模型优势 + 推广价值 | 200-250 字 | □ 完整 |

**第二段内部**（每个子问题都要有）：
- 问题一：□ 模型名称 □ 求解算法 □ 量化结果
- 问题二：□ 模型名称 □ 求解算法 □ 量化结果
- 问题N：□ 模型名称 □ 求解算法 □ 量化结果

## 第3审：内容完整性

| 核心要素 | 检查标准 | 自检 |
|---------|---------|------|
| 数据预处理 | 写明了处理方法（如 3σ+IQR+线性插值），数据类题必写 | □ 有 / □ 无 |
| 模型名称 | 准确写出每问模型全称 | □ 有 / □ 无 |
| 求解算法 | 写明求解软件与算法 | □ 有 / □ 无 |
| 量化结果 | 所有结论量化（精确到 1-2 位小数） | □ 有 / □ 无 |
| 创新点 | 明确写出模型改进/算法优化/思路创新 | □ 有 / □ 无 |
| 检验内容 | **至少两种检验**（灵敏度+稳健性 / 误差+对比） | □ 有 / □ 无 |
| 无空话 | 无"效果显著""有所提升"等模糊描述 | □ 通过 / □ 不通过 |

## 第5审：数据一致性

| 检查项 | 标准 | 自检 |
|--------|------|------|
| 数值一致 | 摘要每个数值与正文图表、`state` 结果完全一致 | □ 一致 / □ 有出入 |
| 前后一致 | 摘要前后无矛盾数据 | □ 一致 / □ 有矛盾 |
| 小数位规范 | 误差/提升率保留 1-2 位小数（7.9%、4.12%） | □ 规范 / □ 不规范 |
| 指标名称 | 专业指标用通用名称（RMSE/MAPE/R²） | □ 规范 / □ 不规范 |
| 无编造 | 所有数据可追溯到代码计算结果 | □ 可追溯 / □ 不可追溯 |

---

## 摘要5审铁律

1. 禁止背景铺垫过长（占比不超全文 1/4），头重脚轻；
2. 禁止无量化结果、无创新点、无模型检验三大核心内容；
3. 禁止疑问句、感叹句、主观评价类情绪化语句；
4. 禁止语句冗余、重复表述，一字不多、一字不少；
5. 禁止夸大，数据与正文完全一致（严禁数据造假/前后不符）。

## 摘要写作执行策略（摘自书 §7.3.5）

| 策略 | 执行要点 |
|------|---------|
| 时间规划 | **摘要最后写**：正文→提炼核心数据与创新点→初稿→精简→**5 轮修改定稿** |
| 结构执行 | 三段式字数卡死（150-200 / 450-550 / 200-250） |
| 内容填充 | 四大必备要素（数据处理+模型与创新+量化结果+检验≥2种）缺一不可 |
| 分题型适配 | A 题侧重机理/参数优化；B 题侧重规划/约束；C 题侧重数据清洗/机器学习 |
| 语言精简 | 禁止"随着社会快速发展"等万能套话；合并短句；术语统一 |
| 数据规范 | 与正文完全一致，禁止估算编造；误差保留 1-2 位小数 |
| 创新凸显 | 改进点放句中核心位置；"相较传统模型，XX 指标降低/提升 XX%" |
| 自查验收 | 逐项核对以上 5 审清单，全部达标再定稿 |
